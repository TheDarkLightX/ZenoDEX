# Research (notes + corpora)

This folder stores *text-format research notes* that seed new protocol math, algorithms, and UX features.

- `papers.md`: curated paper list + implementation takeaways.

Guidelines:
- Prefer arXiv/peer-reviewed sources when available.
- Don’t paste full paper PDFs/text (keep to short summaries and implementation-oriented notes).
- When a note proposes a new algorithm, state: (1) goal, (2) invariants/obligations, (3) deterministic tie-break, (4) how it can be Tau-verified.
