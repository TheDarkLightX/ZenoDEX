# FIRE Revenue Math Visualizations

These figures are generated by Julia without external plotting packages:

```bash
julia docs/assets/fire-revenue-math/run_visualizations.jl
```

## Figures

- `math_ladder.svg` / `math_ladder.csv`
  - policy search size, survivor count, receipt corpora, and execution-derived
    review caps.
- `receipt_outcomes.svg` / `receipt_outcomes.csv`
  - accepted vs rejected receipt rows for v190, v191, and v192.
- `execution_value_ranges.svg` / `execution_value_ranges.csv`
  - runtime-derived route surplus and exact-out savings ranges.
- `review_caps.svg` / `review_caps.csv`
  - v192 review caps against the 2500 bps retail hard rail.

## Claim Boundary

The figures summarize replay artifacts. They are not market forecasts and do
not turn fixture-derived caps into launch parameters.
