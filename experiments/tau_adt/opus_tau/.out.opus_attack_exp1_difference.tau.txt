tau> # ATTACK on exp1 / exp6 - the complement operators are unsound for any probe

tau> # that is not time-constant. One root cause, stated and then repaired.

tau> # ============================================================================

tau> # A table is written { A } | { B }. A tau constant is read under an implicit

tau> # `always`, so that value is (always A) OR (always B) - NOT always(A OR B).

tau> # The two differ, and the gap is exactly the set of streams that move

tau> # between rows over time. Every operator built on the COMPLEMENT of a table

tau> # (exp1's MEMBERSHIP and DIFFERENCE, exp6's ADDED and REMOVED) inherits the

tau> # gap: a row that sits in the table at every single instant is nevertheless

tau> # outside it as a value, so DIFFERENCE keeps it and the audit diff flags it.

tau> #

tau> # Columns are sbf here on purpose: the same attack in bv[8] is real but the

tau> # engine prints cvc5 translation failures alongside the verdict
