# UPBA Bounded Price-Grid Completeness Receipt

Purpose: close the gap between finite audited-set optimality and exact global
weak optimality over a configured bounded integer price grid.

Aristotle project submitted:

```text
b13d05d2-05d5-49b2-9feb-f29427562537
```

The submitted packet asks Aristotle to prove four theorem statements in a small
standalone Lean project:

- `priceGrid_complete`
- `priceGridCandidates_complete`
- `priceGridCandidates_complete_audit_set`
- `price_grid_upper_bound_certificate_implies_global_weak_optimal`

Local accepted theorem surface in `lean-mathlib/Proofs/UniformBatchOptimality.lean`:

- `Price`
- `PriceInGridBounds`
- `priceGrid`
- `priceGridCandidates`
- `FeasibleGridCandidate`
- `priceGrid_complete`
- `priceGridCandidates_complete`
- `priceGridCandidates_complete_audit_set`
- `price_grid_upper_bound_certificate_implies_global_weak_optimal`

Core interpretation:

```text
winner feasible in bounded grid
and upper-bound certificate checks over scoreAt(priceGrid)
-> winner globally weakly optimal over all candidates generated by bounded grid prices
```

This is exact over the configured bounded grid. It does not prove that the grid
bounds or resolution cover every economically relevant rational price.

Boundary: the theorem is model-level until runtime candidate generation proves
or checks that the audited candidate list is exactly `scoreAt(priceGrid)` for the
configured bounds and deterministic scorer.
