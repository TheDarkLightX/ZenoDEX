# Spot V2 shared execution candidate

Native replay and the candidate RISC Zero entrypoint import
`prepare_spot_swap_global_from_frame_v2` from the existing pure Rust Spot crate.
There is one economic transition implementation. The shell reads bounded bytes;
the core decodes, validates and computes; the guest commits the returned journal.
The native guest binary exits unsuccessfully instead of impersonating zkVM execution.

## Candidate transport and journal

The inner frame is `ZDSS2\0` followed by six nonempty u32LE-length-prefixed
canonical JSON components, in this order: complete assets, complete Spot state,
complete global state, full SwapIntent command body, occurrence, block timestamp.
Each component is at most 1 MiB; the total is at most 6,291,486 bytes. The outer
stream is one u32LE frame length, that exact frame and EOF. Lengths are checked
before allocation or slicing. Each decoded component must re-encode to its
original bytes, rejecting duplicate keys, missing optional fields, number-object
aliases and noncanonical whitespace. Integer quantities retain exact precision.

Only an accepted transition emits this canonical journal:

```json
{"input_root":"0x...","refinement_root":"0x...","schema":"zenodex/spot-swap-global-statement/v2"}
```

The input root binds the complete command, occurrence, timestamp and pre-state
root. Projection checks bind the asset and Spot snapshots to that state.
The refinement root binds the pre/post roots, complete state delta and economic,
terminal and oracle effect plans. A verifier must open both commitments against
one exact context, admit the image/profile mapping, authenticate time and command,
and obtain current publication authority. The journal alone grants none of these.

The complete successor assets, Spot and global state must also fit the 1 MiB
component ceiling. `SuccessorBounds` emits no journal, even where the underlying
economic transition succeeds. Retained controls cover a full input whose replay
insertion crosses this ceiling and a nearby representable successor. Global row
bounds permit larger states; a production lifecycle/capacity policy is unresolved.
This candidate format does not replace the older JSON-lines parity transport,
existing custody/margin frames, historical journals or release profiles.

## Native verification

With Rust 1.90 and cached dependencies, from the repository root:

```bash
cargo +1.90.0 test --offline --locked --manifest-path zk/spot_swap_global_risc0/Cargo.toml -j 2
cargo +1.90.0 clippy --offline --locked --manifest-path zk/spot_swap_global_risc0/Cargo.toml --all-targets -j 2 -- -D warnings
python -m pytest -q tests/core/test_spot_swap_execution_frame_v2.py
```

Select a target filesystem with at least 4 GiB free and keep each native target
below 1 GiB. The test harness removes its own temporary mutation targets.
Tests compare 218 existing complete transition cases against Python, check
canonical and structural refusals, capacity, truncation and exact EOF, and kill
compiled original-byte and journal-binding mutants with passing controls.

The lockfile is generated by
`cargo generate-lockfile --offline --manifest-path zk/spot_swap_global_risc0/Cargo.toml`.
RISC Zero SDK/build dependencies are pinned to the repository's existing 3.0.6
(Apache-2.0); the lock resolves 261 packages. The native default member does not
build those target-only guest or methods dependencies. These dependencies enable
the candidate zkVM entrypoint; native core/replay remain the removal alternative.
Pinning and a lockfile do not replace a dependency security or guest-build review.

## Qualification still required

The actual zkVM target, generated methods/image ID, execution cycles, memory,
genuine receipt, independent verifier admission and Spot publication route have
not been qualified. Building the methods explicitly requires the actual RISC Zero
toolchain; `RISC0_SKIP_BUILD` is rejected. No placeholder image or receipt is used.
Native tests do not establish target equivalence, universal refinement, formal
completion, production authority, finality, terminal delivery or recovery.
