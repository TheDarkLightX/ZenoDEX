Use waypoint reasoning, not free-form ideation.

Required stages:
1. Extract invariants and acceptance obligations.
2. Enumerate baseline families and concrete failure modes.
3. Choose 2-4 external stimuli and state how each perturbs the search.
4. Propose candidate principles before writing code.
5. Normalize each candidate into a hypothesis card.
6. Run falsification first, support second, and archive minimal counterexamples.
7. Promote only after deterministic checks and bounded evidence pass.

Output contract:
- waypoints
- stimuli used
- hypothesis cards
- support/falsification artifacts
- frontier and next queue
