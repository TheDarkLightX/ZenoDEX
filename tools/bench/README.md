# Benchmarks / Diagnostics

This directory contains ad-hoc performance and integration diagnostics that are
useful locally but are intentionally **not** part of the `pytest` suite.

## Tau Inlining Bench

```bash
python3 tools/bench/tau_inlining_bench.py
```

## Tau Runner Integration Bench

```bash
python3 tools/bench/tau_runner_integration_bench.py
```
